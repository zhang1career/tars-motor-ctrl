# PMSM 24 V / 60 W / 3000 rpm — Sensorless Speed-FOC (Simulink → STM32F429)

**Not the board firmware.** The STM32F030 runs the hand-written fixed-point
controller in `src/platforms/stm32f030/motor_foc_fx.c`. `codegen_stm32/` is
an F429 float artifact and is not flashed, not an ISR budget check, and not
a numerical reference unless someone rebuilds a side-by-side harness.

Simulation of a 24 V star-wound surface-mount PMSM control system in
MATLAB/Simulink (R2025b), with portable single-precision C code generation
targeted at the **STM32F429** Cortex-M4F.

Control strategy: **sensorless field-oriented control (FOC)** with a
speed outer loop, d/q current inner loops, a flux-observer + PLL for rotor
position/speed estimation, and an open-loop **I/F** startup (align + ramp).

| `codegen_stm32/` | Generated F429 C (`gen_code.m`). Not in Git; rebuild locally. |

## 2. How to run

```matlab
cd motor-ctrl-sim
build_pmsm_ctrl     % build pmsm_ctrl.slx
run_sim(1.2)        % simulate 1.2 s, save plots to results/
gen_code            % generate STM32F429 C into codegen_stm32/
```

Or headless:

```bash
/Applications/MATLAB_R2025b.app/bin/matlab -batch "build_pmsm_ctrl; run_sim(1.2); gen_code"
```

## 3. Motor parameters (ESTIMATED — replace with datasheet values)

These are **typical estimates** for a 24 V / 60 W / 3000 rpm SPMSM, chosen so
the back-EMF fits the 24 V bus with current-control margin. Edit the
"MOTOR (datasheet)" block in `mc_params.m` when you have measured data.

| Symbol | Value | Meaning |
|--------|-------|---------|
| `PolePairs` | 4 | pole pairs (8-pole) |
| `Rs` | 0.45 Ω | stator resistance / phase |
| `Ld = Lq` | 0.6 mH | dq inductance (surface PMSM) |
| `Lambda` | 0.0085 Wb | PM flux linkage (peak) |
| `J` | 1.5e-5 kg·m² | rotor inertia |
| `B` | 1.0e-5 N·m·s | viscous friction |
| `Vdc` | 24 V | nominal bus |
| `Imax` | 5.0 A | peak phase current limit |

Derived: rated torque ≈ 0.19 N·m, torque constant `Kt = 1.5·P·λ ≈ 0.051 N·m/A`,
rated q-current ≈ 3.7 A peak.

Control timing: `Fpwm = 20 kHz` (current loop = PWM rate, 50 µs), speed loop
at 2 kHz, current-loop bandwidth ≈ 1.2 kHz (pole-zero cancellation), speed-loop
bandwidth ≈ 25 Hz, PLL ≈ 40 Hz.

## 4. Simulation results (current tuning)

- Startup: align (0–0.1 s) → I/F ramp to 600 rpm (0.1–0.5 s) → handoff to
  sensorless closed loop.
- Closed loop settles to **1500 rpm (ref 1500)**, estimated speed matches
  actual, steady rotor-angle estimation error ≈ 5° (normal back-EMF observer
  offset), std ≈ 1.6°.
- Load step 0.1 N·m at t = 1.0 s: small dip, clean recovery, `iq → ~2 A`.

## 5. Generated C (STM32F429)

`codegen_stm32/foc_step_stm32.c` — verified results:

- **Single precision throughout** → uses the Cortex-M4F FPU (`cosf`, `sinf`,
  `sqrtf`, `fmaxf`, `fminf`). Parameters are constant-folded (no runtime double
  math).
- Cross-compiled with `arm-none-eabi-gcc -mcpu=cortex-m4 -mthumb
  -mfpu=fpv4-sp-d16 -mfloat-abi=hard -O2`:
  **~1.5 KB flash (text), 56 B RAM (state)**, 114 VFP instructions emitted.

API:

```c
void foc_step_stm32_initialize(void);              /* once at boot */
void foc_step_stm32(real32_t ia, real32_t ib, real32_t ic, real32_t vdc,
                    real32_t speed_ref_rpm, real32_t enable,
                    real32_t *duty_a, real32_t *duty_b, real32_t *duty_c,
                    real32_t *theta_est, real32_t *speed_est_rpm,
                    real32_t *id, real32_t *iq);    /* once per 50 µs */
```

## 6. STM32F429 integration

See `stm32/foc_app.c` for a CubeMX/HAL template. Summary:

1. **TIM1**: center-aligned PWM, 20 kHz, complementary outputs + dead-time,
   drives the 3-phase inverter; TIM1 update triggers the ADC.
2. **ADC** (three-shunt): inject all three phase currents + DC-bus voltage,
   triggered by TIM1. Scale counts → amps/volts (single precision).
3. Call `foc_step_stm32(ia, ib, ic, ...)` in the TIM1-update / injected-EOC ISR;
   the controller removes zero-sequence `(ia+ib+ic)/3` before Clarke.
4. Write returned duties to `TIM1->CCR1..3`.
5. Enable the FPU (CPACR CP10/CP11) and build with hard-float flags above.

**Signals from your control board:** three low-side phase-current shunts
(A/B/C) → 3 ADC channels, plus **DC-bus voltage** (divider → 1 ADC channel).
No position/speed sensor is needed.

### CMSIS-DSP (optional)
The generated code uses `libm` (`sinf`/`cosf`/`sqrtf`), which `arm-none-eabi`
maps to FPU-friendly routines. If you want to force CMSIS-DSP fast-math
(`arm_sin_cos_f32`, `arm_sqrt_f32`), drop CMSIS-DSP under
`~/.matlab/lib/cmsis-dsp/` and we can wire a code-replacement library.
