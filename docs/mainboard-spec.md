### 0.1 V_BOOST 现状的正确结论

半桥板 `D1`（1N4148, `V_BOOST → HB`）与 UCC27211 **片内自举二极管并联**，
两者阳极都在 12 V 附近：

```
低占空比 (HS≈0V)    : V_C3 ≈ 12.6 − 0.8 = 11.8 V    → 落在 8~17 V 推荐窗口，安全
接近 100% duty      : 12.6 − 0.8 − 12 = −0.2 V      → D1 不导通，该路无贡献
```

**没有过压隐患。** roadmap 早期记录的「外部电荷泵 12 V → 约 20 V」与实测 12.6 V 不符，
应据实测修正；基于「20 V」推出的过压结论不成立。

但**高占空比适应性目前并不存在**——高边仍只靠片内自举，高 duty 下仍会掉进 HB UVLO。

真升压的正确形式（非旁路二极管）：

```
V_BOOST ≈ 24 V  且  HB−HS 加 15 V 齐纳钳位 + D1 后串限流电阻

低占空比   : 齐纳钳在 15 V                    (< 17 V 推荐上限, < 20 V Vgs 上限)
100% duty  : min(24 − 0.8 − 12, 15) = 11.2 V  (远高于 7.9 V 最坏 UVLO)
```

单一固定 V_BOOST 经普通二极管灌 HB **无法同时满足两端**：
`V_C3 = V_BOOST − Vf − V_HS`，而 `V_HS` 在 0 与 12 V 之间摆。
24 V 不加钳位时低占空比会把 C3 充到 23.2 V，**超过 20 V 绝对最大值，损坏驱动器**。

### 0.2 本版为何先不需要升压

低边分流采样需要低边导通窗口：

```
死区 1.5 µs + INA240 建立 ~2 µs + ADC 采样转换 ~1 µs ≈ 5 µs
→ 20 kHz (50 µs) 下 duty 上限约 90%
```

> **实测修正（2026-08-27）**：INA240 + 输出 RC 的建立时间实测**约 2 µs**，与此处假设一致
> （示波器测 `ISENSE_V` 在开关沿后到最终值一个量化码内的时间，见 roadmap 4.1）。
> 但 duty 上限没有 90% 那么高：固件为了让转换在控制 ISR 之前完成，把 ADC 序列**提前 7 µs**
> 启动，而四通道扫描本身要 6.67 µs，所以需要的半窗口是 9 µs 而非 5 µs，**上限约 67%**。
> 把 `MOTOR_ADC_LEAD_COUNTS` 减半可推到约 80%。

**比自举失效点（约 95%）更严。** 只要用低边采样，自举极限到不了。
升压真正开始重要是换成 **inline 相线采样**之后（低边采样在高调制度下失明）。
本板电荷泵输出**直接驱动 `V_BOOST`**（无跳线旁路 12 V），默认不启泵时 `V_BOOST` ≈ 10.6 V。

## 1. 电流采样前端

### 1.1 为什么必须差分

三块半桥板各有独立 GND 引线回主板。按 1 nH/mm 估，100 mm 引线约 100 nH；
AOD4184 关断 1.6 A 的电流变化率约 30 A/µs 量级：

```
V = L·di/dt = 100 nH × 3×10⁷ A/s ≈ 伏级瞬态
```

满量程信号仅 `±3 A × 10 mΩ = ±30 mV`。**单端测量在物理上无意义。**
1% 分立电阻搭差分放大器的共模抑制比仅 `1/(4×1%)` ≈ 28 dB，同样不够。
必须用内部修调电阻的电流检测放大器。

### 1.2 器件与工作点

| 项 | 值 | 说明 |
|---|---|---|
| 器件 | **INA240A2D**，增益 50 V/V，SOIC-8 | 内部修调，CMRR 120 dB(DC) / 90 dB(50 kHz) |
| 关键特性 | enhanced PWM rejection | 专为开关电机驱动的共模阶跃设计 |
| 共模范围 | −4 ~ +80 V | `I_SENSE` 续流时低于地；留 inline 升级余量 |
| 供电 | 3.3 V（器件范围 2.7~5.5 V） | 与 ADC 同轨 |
| 带宽 | 400 kHz | 在采样窗口内充分建立 |
| 中轨偏置 | **`REF1`(pin 7) → `GND`，`REF2`(pin 6) → `+3V3A`** | 内部二分得 1.65 V，**比例跟踪 ADC 参考**；接法理由见 §1.2.1 |
| 满量程 | ±2.9 A | `±30 mV × 50 = ±1.5 V`，受输出摆幅(约 0.02~3.1 V)限制 |
| 分辨率 | **1.61 mA/LSB** | `3.3/4096/(50×0.01)`，比裸分流 80.6 mA/LSB 好 **50 倍** |

#### 1.2.1 REF1 / REF2 的分配是布局自由度，不是电气约束

数据表 **SBOS712 §8.4.1** 原文：

> The reference inputs are connected to an internal gain network.
> **There is no operational difference between the two reference pins.**

参考分压精度的定义本身就是对称的（取绝对值）：`VOUT = |(VREF1 − VREF2)| / 2`，
指标 0.02% typ / 0.1% max，**两种接法同一条**。所以中轨 1.65 V、满量程 ±2.9 A、
1.61 mA/LSB、以及 §2 里 `ITRIP_HI/LO` 与本参考同源的比例跟踪，都与分配方向无关。

**采用 `REF1 → GND`、`REF2 → +3V3A`**，两个理由：

1. **TI 自己的应用示例就是这个方向**（§9.2.1.2 的 36 V / 4000 RPM 电机驱动用 INA240A1，
   另一处用 INA240A4），原文：「the reference point is set to midscale by splitting the
   supply with REF1 connected to ground and REF2 connected to supply」。
2. **SOIC (D) 封装上布线更短**：引脚顺序是 `4=GND, 5=VS, 6=REF2, 7=REF1, 8=OUT`，
   `REF2` 与 `VS` **相邻**，这一跳是焊盘到焊盘；`REF1` 只需一个过孔下地平面。
   反过来接则 `VS` 要越过 pin 6 的焊盘去 pin 7，而 `GND` 要挤进 VS 与 REF1 之间。
   附带好处：`VS` 的 100 nF 去耦就在 pin 5，`REF2` 直接共享那个低阻抗点，
   VS 与参考之间不再夹一段走线电感（内部分压会把二者压差的一半搬到输出偏置上）。

唯一的硬约束（数据表 Note，两种接法都满足）：
**不得把 `REF1`/`REF2` 接到低于 `GND` 或高于 `VS` 的电位。**

`check_netlist.py` 按集合判定 `{pin6, pin7} == {GND, +3V3A}`，两种接法都通过 ——
分配方向留给布局。

增益选 A2(50) 而非 A3(100)：工作点绕组电流约 1.6 A，增益 100 在 1.45 A 即削顶。

**KiCad 10.0.3 自带库的 INA240 符号 D / PW 引脚定义互换**，直接使用会烧件。

| 引脚 | KiCad `INA240A2D`(SOIC 封装) | **TI 手册 D (SOIC)** | KiCad `INA240A2PW`(TSSOP 封装) | TI 手册 PW (TSSOP) |
|---|---|---|---|---|
| 1 | IN− | **NC** | NC/GND | IN− |
| 2 | GND | **IN+** | IN+ | GND |

### 1.4 每通道外围

```
J_ISx.1 (shunt 低端 = 半桥 GND) ──10Ω──┬── INA240.IN−  (pin 3)
                                       1nF (差分)
J_ISx.2 (shunt 高端 = I_SENSE)  ──10Ω──┴── INA240.IN+  (pin 2)

INA240.OUT (pin 8) ──100Ω──┬── MCU PA1/PA2/PA3
                          1nF → AGND        (fc ≈ 1.6 MHz)
```

- 输入串阻 **10 Ω 且必须匹配**：INA240 输入偏置电流经串阻产生增益误差，阻值要小。
- 差分 1 nF 仅限边沿速率，不做主滤波（主滤波靠**同步采样**，不靠 RC，避免引入延迟）。
- 输出 RC 供 ADC 采样保持电容充电，1.6 MHz corner 不引入可观延迟。
- 每片 INA240 就近 100 nF 去耦；每组 10 µF 体电容。

## 2. 过流保护（半桥板无 nFAULT，必须自建）

半桥板 `J3` 仅 4 线：`PWM_LIN` / `PWM_HIN` / `GND` / `V_BOOST`。
UCC27211 本身无故障输出引脚。因此 `board_pins.h` 中

```c
#define BOARD_PWM_BKIN_PIN  GPIO_PIN_6  /* PA6 TIM1_BKIN — nFAULT */
```

是 **TARS 遗留定义，物理上无处可接**。这解释了历史上启用 BKIN 导致 MOE 锁死（引脚悬空）。

STM32F030 **无片内比较器**（F031/F051 才有），故用外部窗口比较器：

```
每相 2 个比较器（正向 / 反向越限）× 3 相 = 6 个 → 2 × LM339（8 路，剩 2 路做过温，见 §6.2）
6 路开集输出线或 → nFAULT → JP2 → PA6 (TIM1_BKIN)，R16 4.7 kΩ 上拉至 +3V3
过温 2 路线或到独立的 nOTEMP → D5 单向注入 nFAULT，并直连 PA12（§6.2）
```

阈值（±2.5 A 跳闸）：`1.65 ± 2.5 × 0.01 × 50 = 1.65 ± 1.25 V` → **0.40 V / 2.90 V**。

比较逻辑（LM339 开集输出在 `V+ < V−` 时拉低）：

| 功能 | `+` 输入 | `−` 输入 | 拉低条件 |
|---|---|---|---|
| 正向越限 | `ITRIP_HI` (2.90 V) | `IOUT_x` | `IOUT_x > 2.90 V`，即电流 > +2.5 A |
| 反向越限 | `IOUT_x` | `ITRIP_LO` (0.40 V) | `IOUT_x < 0.40 V`，即电流 < −2.5 A |
| 过温 2 路 | `OTEMP1` / `OTEMP2` | `ITRIP_LO` (0.40 V) | `OTEMPn < 0.40 V`，即远端 NTC 过热（§6.2） |

**8 路全部有实际功能，没有置死单元。** 过温那两路输出接 `nOTEMP` 而非 `nFAULT`，
理由见 §6.2 —— `nFAULT` 是线或，无法区分故障源。

### 2.1 LM339 必须用 12 V 供电（不能用 3.3 V）

LM339 是 Darlington 输入级，**输入共模上限只到 `VCC − 1.5 V`**
（TI 应用手册 SNOAA35 明确建议全温区按 `VCC − 2 V` 设计）：

| 供电 | 推荐共模上限 | 能否容纳 2.90 V 阈值 |
|---|---|---|
| 3.3 V | 1.3 V | **否** |
| 5 V | 3.0 V | 勉强，无余量 |
| **12 V** | **10 V** | **可以，余量充足** |

`LMV339`（低压版）在 3.3 V 下共模上限同样不够，也不能用。
因此 **LM339 的 `V+` 接 `+12V`、`V−` 接 `GND`**；输入信号 0.15~3.15 V 落在共模范围中部，
开集输出上拉到 `+3V3`，MCU 引脚电平安全。这是开集输出的天然好处——供电轨与逻辑电平可以分开。

阈值分压串（从 `+3V3A` 取，与 INA240 的 REF **同源以保持比例跟踪**）：

```
+3V3A ──[R 4.02k]── ITRIP_HI ──[R 24.9k]── ITRIP_LO ──[R 4.02k]── GND     (1%, E96)

ITRIP_HI = 3.3 × (4.02+24.9)/32.94 = 2.897 V      分压串电流约 100 µA
ITRIP_LO = 3.3 ×  4.02/32.94       = 0.403 V
```

两个阈值节点各加 100 nF 对地去耦。LM339 输入偏置电流约 25 nA，
在 33 kΩ 分压阻抗上仅产生约 0.8 mV 误差，可忽略。

`JP2` 可断开，避免重复历史上 MOE 锁死的坑（见 §0 与 roadmap 待决项 #4）。

### 3.1 ADC 触发源：不占引脚

F030 可用 ADC 外部触发（HAL 头文件实测）：

```
ADC1_2_EXTERNALTRIG_T1_TRGO / T1_CC4 / T2_TRGO / T3_TRGO / T15_TRGO
TIM1 MMS: TIM_TRGO_UPDATE / TIM_TRGO_OC1REF … TIM_TRGO_OC4REF
```

**采用 `TIM1_TRGO` ← update 事件。** 中心对齐 + `RCR=1` 时每 PWM 周期一次，
落在计数器峰值 —— 正是低边导通窗口中心。全程内部信号，**不占用 PA11**。

> roadmap 待决项 #2 需修正：CC4 作为 ADC 触发是**内部事件**，
> 只有 CH4 的**引脚输出**才与电荷泵抢 PA11；但 CCR4 会被电荷泵占用，
> 故改用 TRGO/update 完全避开，两边都不牺牲。

> **TIM3 与 Hall**：F030 LQFP-32 上 TIM3 只有 **PB4=CH1**、**PB5=CH2** 可用（CH3/CH4 与 PWM 低侧冲突）。
> 因此 **HALL_B→PB4、HALL_C→PB5** 可硬件捕获，**HALL_A→PB3** 仅 GPIO/EXTI；
> 三路可共用 TIM3 时基，B 通道在边沿中断里锁存 `TIM3->CNT` 即可。
>
> **TIM3 冲突提醒**：`motor_cycles.c`（阶段 A2）把 TIM3 用作 48 MHz 自由运行周期计数器。
> 若启用 Hall 捕获，须统一 TIM3 用途（同一时基 + 输入捕获，或改 cycle bench 用别的定时器）。

## 4. 供电

```
J1 ─[F1 2A 自恢复]─┬─[D7 SMBJ14A]─ GND        (输入保护，见 §4.1)
                   └─[D6 SS34]─→ +12V
+12V ─┬─ AMS1117-3.3 (SOT-223) → +3V3 ─┬─ 数字 (VDD)
     │                       │                                └─ 磁珠 → +3V3A (VDDA, INA240 VS, REF)
     ├─ J21（螺钉端子，三块半桥板的功率供电，与 J1 并联）
```

### 4.1 输入保护（`F1` / `D6` / `D7`）

**关键约束：`J21` 给三块半桥板供电，母线电流全部经 `F1` 和 `D6`。**
所以这两个器件按「板上过流阈值允许的母线电流」定额，而不是按逻辑电流：

| 参考点 | 母线电流 | 来源 |
|---|---|---|
| 空载 | 0.05~0.07 A | roadmap 1.2 实测 |
| duty 20% 工作点 | 0.26 A | roadmap 3.3 实测 |
| 当前电源限流 | 1.6 A | roadmap 0.5（阶段 F 前须提高） |
| **`ITRIP` 阈值允许的上限** | **约 2.2~2.5 A** | §2 阈值 ±2.5 A/相，高占空比下母线≈相电流 |

| 器件 | 值 | 说明 |
|---|---|---|
| `F1` | 2 A 自恢复保险丝（PPTC，1206） | 标称值是**保持电流**；跳闸约 2× 保持、秒级动作。60 °C 环温降额后有效约 1.4 A。**它保护线缆与电源，挡不住瞬时短路** |
| `D6` | **SS34**（3 A / 40 V，SMA） | 串联反接保护。1 A 的 SS14 会成为链上最弱环——`F1` 要到约 4 A 才动作，永远保护不了它 |
| `D7` | **SMBJ14A**（600 W，SMB），接在 `F1` 与 `D6` **之间** | 截止 14 V / 击穿 15.6~17.2 V / 钳位 23.2 V |

**`D7` 的位置是有意的**（不在 `+12V` 上）：`F1` 在它上游 → 持续过压时保险跳闸而不是 TVS 烧毁；
它在 `D6` 上游 → 浪涌电流不必穿过 `D6`；反接时单向 TVS 正向导通 → 帮助拉跳 `F1`。

**必须认清 TVS 的能力边界**：12 V 轨的 TVS 钳位必然在 23 V 以上，而 `AMS1117` 输入绝对最大值
**15 V**、经 `J21` 供到半桥板的 `UCC27211` VDD 绝对最大值 **20 V**。所以它只吸收
**快速大能量瞬态**（带载拔电源时电机电感反冲、热插拔），**挡不住持续过压**——误插 24 V 电源
照样烧 LDO，这条链里没有器件能防。

**串联压降的代价**：`SS34` 在 1.6 A 下约 0.4 V、2.5 A 下约 0.45 V（约 1.1 W），
直接从 12 V 母线里扣掉，也让 roadmap 0.5 的电源塌陷更严重。**`D6` 需要敷铜散热**（见 §7）。
若将来母线电流超过约 2.5 A，正确升级是 **P 沟道 MOSFET 理想二极管**（2 A × 30 mΩ = 0.06 V）。

`VSENSE_12V`（`R30`）取样在 `D6` **之后**，所以固件量到的是真实的二极管后母线，
FOC 的 `vdc` 不需要补偿；电荷泵的 `D2` 同样从二极管后取电，`V_BOOST` 因此比理想值低约 0.4 V。

**母线储能 30 µF**（`C1`/`C35`/`C37` 各 10 µF，外加 `C25`/`C26`/`C27`/`C36` 各 100 nF）。
2 A 的 20 kHz 斩波下 `ΔV = I·t/C = 1 A × 25 µs / 30 µF ≈ 0.8 V` 峰峰。
**这个交流分量必须由板上电容就近吸收**——否则它会经 `F1`/`D6`/杜邦线来回跑，
把 PPTC 的热效电流抬到直流均值之上、更易误跳。`C37` 就是为此补的第三只 10 µF。
半桥板侧仍应有自己的 VIN 体电容，见 roadmap 0.5「储能加在 VIN」。

**采用单级 LDO，不用开关电源。** 负载估算：
MCU 约 15 mA + 3 × INA240 各 2.4 mA + 3 × Hall 约 10 mA + 杂项 ≈ 60~70 mA，设计上限取 100 mA。

| 方案 | 12V→3.3V @100 mA 耗散 | 噪声 | 结论 |
|---|---|---|---|
| **单 LDO (SOT-223)** | 0.61 W @70 mA / 0.87 W @100 mA；SOT-223 约 60 °C/W → 升温约 37~52 °C | **无开关噪声** | **采用** |
| buck 5V + LDO 3.3V | LDO 仅 0.17 W | 开关节点靠近 30 mV 模拟信号 | 负载这么小时不值得 |
| 单 buck 直出 3.3V | 最低 | 开关噪声直接进模拟轨 | 否 |

在 70 mA 这个量级，LDO 的热损耗完全可以接受（SOT-223 配敷铜，结温约 62~77 °C），
而**彻底没有开关节点**对 ±30 mV 的分流信号是实打实的好处。
`AMS1117-3.3` 输入上限 15 V，12 V 输入有余量。LDO 布局上远离三片 INA240。

若将来负载显著增加（加显示、更多传感器）再改两级，本板不预留 buck 位置。

**板载 3.3 V 取代 nanoDAP 供电**：roadmap 已把「探头供电」列为误判来源
（探头掉线表现为「母线 0.000 A 且完全无 PWM」，极易误判成硬件坏）。

### 5.1 `J21`：三块半桥板共用一个功率端子

用螺钉端子而不是 2.54 mm 针座：`ITRIP` 阈值允许的母线电流约 2.5 A，超出针座的合理范围；
Phoenix MKDS-1,5 按 1.5 mm² 端子额定约 13.5 A，余量充足。三块半桥板在**板外并接**到这一个端子。

两个由此产生的注意点：

1. **三块板的功率地在板外汇合**，不再各自有独立回流脚。这对分流采样无影响——
   INA240 是差分测量（§1.1），板间共模差由它的 120 dB / 90 dB@50 kHz 抑制掉。
   但共用回流线上跑的是三相斩波电流的**和**，稳态基波相互抵消而开关分量不抵消，
   所以这根线要短、要粗，最好与 `+12V` 那根**紧贴走**以减小回路面积。
2. **`H1`/`H2`/`H3` 是接地的 M3 安装孔**（`MountingHole_Pad`，焊盘接 `GND`）。
   若机箱另有接地点，注意不要形成大面积地环。

**`J_IS1..3` 的两根线在 PCB 上与电缆里都必须作为紧耦合差分对处理**——
共模是主误差源（见 1.1）。电缆建议双绞。

**Hall 供电为 `+3V3`，不设跳线。** `board_pins.h` 标注 3.3 V，且实测已证实
（hall6 闭环正常换相，10 s 读到 311 个 Hall 边沿），因此无需保留 5 V 选项与选择跳线。
Hall 信号线上拉同样接 `+3V3`（见 §6），保证 MCU 输入不超过 3.3 V。

### 6.2 远端 NTC 过温保护（LM339 余下 2 路）

板载 `RT1`（PA0）量的是**主板温度**，主要被 LDO 那 0.6~0.9 W 主导，**看不到半桥板 MOSFET 与电机**——
而 roadmap 记录的过热事故正是「3 号板过热」，阶段 G 还有永磁体不可逆去磁风险。
ADC 通道已用尽（MCU 自带 die 温度与 VREFINT 只覆盖板级），**比较器不需要 ADC 通道**，正好补这个盲区。

```
+3V3A ──[R38 10k]──┬── OTEMP1 ──┬── J14.1   (J14.2 = GND，外接 10k NTC)
                   │            ├──[C30 100nF]── GND
                   │            ├──[R39 100k]── nOTEMP      (迟滞)
                   │            └── U7C.11 (+)
U7C: − = ITRIP_LO   out = nOTEMP          (OTEMP2 / R41 / C31 / R42 / U7D 同构)

+3V3A ──[R40 4.7k]── nOTEMP ──┬── U1.22 (PA12, EXTI12) + TP5
                              └── D5 (BAT54) K ── A ── nFAULT
```

**门限白蹭现成的 `ITRIP_LO`。** 分压方向是「上拉 + NTC 对地」，温度升高 → 节点电压**下降**；
分压串与 `ITRIP_HI/LO` 同取自 `+3V3A`，保持比例跟踪。

**选用 NTC：10 kΩ @25 °C，B = 3435。**
**两路门限不同** —— 每路有自己的上拉与迟滞电阻，只有阈值节点 `ITRIP_LO` 共享，
所以上拉阻值就是该路的门限旋钮：

| 通道 | 探头位置 | 上拉 / 迟滞 | 跳闸 | 恢复 | 迟滞 | 依据 |
|---|---|---|---|---|---|---|
| `OTEMP1` | **半桥板 MOSFET** | `R38` 10 k / `R39` 100 k | **90 °C** | 86 °C | 3.9 °C | AOD4184 `Tj,max` 150 °C，余量充足 |
| `OTEMP2` | **电机磁钢 / 绕组** | `R41` 13 k / `R42` 150 k | **80 °C** | 77 °C | 3.2 °C | N35 类烧结钕铁硼工作上限约 80 °C，见 roadmap 阶段 G 去磁风险 |

（跳闸门限对应的 NTC 阻值：`OTEMP1` 1.26 kΩ、`OTEMP2` 1.66 kΩ；恢复门限 1.40 / 1.82 kΩ。）

门限数字用单 B 值模型算，在 90 °C 处与厂家 R–T 表可能差 2~3 °C；叠加 NTC 与电阻的
1% 容差，实际按 **±5 °C** 看待，需要精确值时以厂家 R–T 表复核。

**`D5` 必须是肖特基，且方向是「A 在 `nFAULT`、K 在 `nOTEMP`」**，这样耦合是单向的：

| 事件 | `nOTEMP` | `nFAULT` | PA12 | 结果 |
|---|---|---|---|---|
| 过温 | U7C/D 拉低 | 经 `D5` 钳低 | **低** | BKIN 跳闸 + 固件知道是过温 |
| 过流 | 高（`D5` 反偏） | U6/U7 拉低 | **高** | BKIN 跳闸 + 固件知道**不是**过温 |

若用硅二极管，过温时 `nFAULT` 低电平 = `V_OL(LM339 最坏 400 mV) + Vf(0.55 V) ≈ 0.95 V`，
逼近 `V_IL ≈ 0.3·VDD ≈ 0.99 V`；BAT54 的 `Vf ≤ 0.32 V` 给出约 0.72 V，余量 270 mV。

三条必须记住的性质：

1. **迟滞电阻只能接 `nOTEMP`，绝不能接 `nFAULT`** —— 否则任一路过流都会去搬动过温门限。
2. **两路迟滞共用 `nOTEMP`**，所以 2 号探头跳闸会把 `OTEMP1` 也拽低约 40 mV（≈3 °C）。
   因为两路本来汇成同一个标志、BKIN 又是锁存的，这个交叉耦合无实际后果。
3. **`J14`/`J15` 空置时 `OTEMPn` = 3.3 V = 不跳闸**。失效方向是「不误跳」，
   探头脱落不会被察觉；这是有意的取舍。
4. 过温这一路的「停用开关」就是**把 NTC 拔掉**，所以不需要跳线；整条 `nFAULT → PA6`
   仍可由 `JP2` 断开。

## 7. 布局要点（PCB 阶段验收项）

1. **分流 Kelvin 对**：`J_ISx` 两脚到 INA240 输入走紧耦合差分对、等长，
   中间不跨地平面分割，远离 PWM 走线与功率回流路径。
2. **地分区**：`AGND`（INA240 + VDDA + REF 分压）与 `GND`（数字 + 连接器）
   单点连接，连接点置于 MCU VSS/VDDA 附近。
3. **LDO 及其散热敷铜**远离三片 INA240（0.61 W 的热源，避免热梯度）。
   **`D6` 同样需要敷铜**（2.5 A 下约 1.1 W），并与模拟区分开。
4. **PWM 六路**尽量等长、同臂 H/L 相邻成对，远离模拟区。
5. INA240 去耦电容紧贴 VS 引脚。
6. 电荷泵升压级（预留）与模拟区物理分离。

### 9.5.1 PA4 母线电压检测（必需，此前是缺口）

`foc_step_stm32(ia, ib, ic, **vdc**, ...)` 把母线电压当**必需输入**，
而原设计没有任何测量手段。FOC 用 `vdc` 归一化 SVPWM 占空比，
写死 12 V 会在电源塌陷（撞 1.6 A 限流）时让输出占空比成比例出错。

```
+12V ──[R30 39k]──┬── VSENSE_12V (PA4)
                  ├──[R31 10k]── GND
                  └──[C28 100nF]── GND
```

分压比 4.9：12 V → 2.449 V，满量程 16.2 V，**3.95 mV/LSB**，分压串耗流 245 µA。
固件侧网络名仍对应 ADC 通道 `ADC_IN4`。

### 9.5.2 PA5 V_BOOST 监测

```
V_BOOST ──[R32 68k]──┬── VSENSE_V_BOOST (PA5)
                     ├──[R33 10k]── GND
                     └──[C29 100nF]── GND
```

分压比 7.8，满量程 25.7 V：12.6 V 读 1.62 V，22 V 读 2.82 V。
固件侧对应 `ADC_IN5`。作用是让固件能**直接看到自举/电荷泵塌陷**，
而不是靠电机停转反推——正是 §0.1 讨论的那个高占空比失效模式。

### 9.5.3 板载电荷泵（3-BJT + PA11，无 555 / 无 TC4427）

沿用 `charge-pump/pcb` 的**二极管倍压 + 互补推挽**（`Q1`/`Q2`），振荡源改为 `PA11 = TIM1_CH4`。
PA11 **不能直接驱动** `Q1`/`Q2` 基极（ngspice：3.3 V 直驱 `CP_SW` 仅 2.21 V 峰峰值，
`V_BOOST` 停在 12.2 V 完全不倍压）。

增加 **`Q3` 电平移位 + `R28` 上拉**（`reports/cp_bjt_compare.cir` 方案 D）：

```
PA11 ──[R25 2.2k]── Q3.B ── Q3.E=GND ── Q3.C=CP_BASE ──[R28 470R]── +12V
CP_BASE ── Q1.B / Q2.B ；  Q1(NPN) C=+12V ；  Q2(PNP) C=GND ；  Q1.E=Q2.E=CP_SW
CP_SW ──[C32 47nF]── CP_PUMP ── D2(+12V充电) / D3(→V_BOOST)
V_BOOST ── C34 100nF ∥ C38 10uF ── GND ；  +12V ── C35/C36 去耦
```

| 器件 | 值 |
|---|---|
| `R25` | 2.2 kΩ（PA11 → Q3 基极） |
| `R28` | 470 Ω（+12V 上拉）——**非关键值，220 Ω~2.2 kΩ 等效，见下** |
| `C32` | **470 nF / 0805** ——决定输出阻抗的唯一参数，见下 |
| `R43`/`R44` | 0 Ω，Q1/Q2 各一只独立 base stopper（见下） |
| `Q1`/`Q3` | SS8050；`Q2` SS8550 |

输出**直接驱动 `V_BOOST`**（无 `JP1`、无 TC4427）。停泵时 `V_BOOST` ≈ 10.6 V。
**`Q1`/`Q2` 是互补射极跟随器**（B 经各自 stopper 接 `CP_BASE`、E 共接 `CP_SW`），不是图腾柱：
`V_BE(Q1) = CP_BASE − CP_SW` 与 `V_BE(Q2)` 恒为等值反号，结构上排除直通，
所以 `CP_BASE` 到两管基极**不需要串限流电阻**（`R28` 本身就是上升沿的限流元件）。

`R43`/`R44` 是防**射极跟随器带容性负载寄生振荡**的 base stopper，装 0 Ω；
若实测 `CP_SW` 有高频振铃再换约 22 Ω。**必须每管一只独立**——
在公共节点串一只不是 stopper，只是把 `R28` 变大。

**与 TC4427 取舍：** 选 3-BJT 因成本。固件用 PA11 PWM + PA5 监测闭环调节。

#### 电荷泵实测（ngspice，`reports/cp_r28_sweep.cir` / `cp_load_sweep.cir` / `cp_c32_sweep.cir`）

> 早期 `cp_bjt_compare.cir` 把 `Q1`/`Q2` 的 `nb`/`ne` 写反（ngspice 是 `Q nc nb ne`），
> 导致 `CP_SW` 多数时段悬空；且 10 µF 储能配 47 kΩ 是 470 ms 时间常数，15 ms 根本没到稳态。
> 两处都已修正，下表是修正后的结果。**旧结论「470 Ω 上拉使 `CP_SW` ≈ 11.6 V p-p」作废。**

`R28` 扫描（负载 1 mA）——**摆幅与输出电压几乎不随 `R28` 变化**，只影响峰值电流：

| `R28` | `CP_SW` p-p | `V_BOOST` | `C32` 峰值电流 |
|---|---|---|---|
| 220 Ω | 10.78 V | 20.63 V | 94 mA |
| **470 Ω（现值）** | 10.82 V | 20.68 V | 65 mA |
| 1 kΩ | 10.82 V | 20.71 V | 44 mA |
| 2.2 kΩ | 10.80 V | 20.72 V | 28 mA |

**倍压器的输出阻抗 ≈ `1/(C32·f)` = `1/(47n × 20k)` = 1.05 kΩ**，这才是决定性参数：

| 负载 | `V_BOOST` | 纹波 |
|---|---|---|
| 0.1 mA（近空载） | **21.67 V** | 11 mV |
| 1 mA | 20.68 V | 44 mV |
| 3 mA | 18.78 V | 148 mV |
| 10 mA | **11.32 V**（完全塌陷，不再倍压） | 488 mV |

`C32` 扫描（负载 3 mA）——加大 `C32` 同时改善输出电压**并降低**峰值电流
（同样的每周期电荷量摊在更大的电容上，`ΔV` 更小、导通窗口更长）：

| `C32` | `V_BOOST` @3 mA | 峰值电流 |
|---|---|---|
| 47 nF（原值） | 18.78 V | 232 mA |
| 100 nF | 20.12 V | 140 mA |
| **220 nF** | **20.81 V** | **70 mA** |
| 470 nF | 21.06 V | 35 mA |

→ **已采用 470 nF / 0805**（选 50 V 以限制直流偏压降容；`CP_SW`–`CP_PUMP` 间直流偏压约 11 V）。
注意这会让 §9.5.4 的低占空比过压更确定，**所以必须先有半桥钳位**。

### 9.5.4 关键约束：启用电荷泵前必须给半桥板加钳位

倍压输出 `≈ 2×12 − 2×Vf`，ngspice 实测近空载 **21.7 V**（与手算 22 V 一致）。
代入 §0.1 的关系 `V_C3 = V_BOOST − Vf − V_HS`：

| 工况 | `V_C3` = `VHB−VHS` | 判定 |
|---|---|---|
| 低占空比 (`V_HS≈0`) | 21.7 − 0.8 = **20.9 V** | **超过 20 V 绝对最大值** |
| 接近 100% duty (`V_HS≈12`) | 21.7 − 0.8 − 12 = 8.9 V | 高于 7.9 V 最坏 UVLO ✓ |

也就是说约 22 V 能解决高占空比，但会在**正常低占空比工作点损坏驱动器**。
（这个结论在修正后的仿真下依然成立，见 §9.5.3 的实测表。）

根因是 §0.1 已给出的：`V_HS` 摆幅 12 V，而 `V_C3` 的允许窗口（UVLO 8 V ~ 推荐上限 17 V）
只有 9 V 宽，**没有任何固定 V_BOOST 能同时满足两端**。

→ **未加半桥钳位前不要启泵。** 输出直接驱动 `V_BOOST`（无 `JP1` 旁路 12 V）。
要在每块半桥板的 `C3`（HB–HS）两端加 **15 V 齐纳钳位** + `D1` 后串限流电阻。
加了钳位后：低占空比钳在 15 V ✓，100% duty 得 `min(21.7−0.8−12, 15) = 8.9 V` ✓。
高占空比余量偏薄（最坏 UVLO 7.9 V），这也是把 `C32` 加大到 220 nF 的另一个理由：
高 duty 时 `V_BOOST` 要顶住三路自举的补充电流，输出阻抗越低越好（§9.5.3 负载表）。

`D4` 在板上是 **3.3 V 状态 LED**（`R34` 限流），不是 V_BOOST 齐纳。
V_BOOST 过压保护仍须靠半桥板 HB–HS 钳位，不能靠主板齐纳。

## 9.6 PA14 复用 SWCLK / USART1_TX（已采纳）

### 9.6.1 决定与依据

`PA14 AF0 = SWCLK`，`AF1 = USART1_TX`（数据手册脚注 (2)：x4/x6 器件可用，K6 属于 x6）。
STM32 的 AF 多路器**同一时刻只能选一个功能**，两者互斥。

采纳复用，理由：I2C（PB6/PB7）是运行期控制接口不能占用；
而 SWCLK 只在调试期使用、串口日志只在发布后运行期使用，**时间上不重叠**。

关键支撑事实（数据手册 §3.5）：

> The boot loader is located in System Memory. It is used to reprogram the Flash
> memory by using USART on pins **PA14/PA15** or PA9/PA10.

**内置系统 bootloader 用的正是 PA14/PA15。** 所以发布固件占用 PA14 做 TX 之后，
仍可通过**同一条串口**、靠 BOOT0 拉高进 bootloader 重新烧录——
「失去 SWD」不再是变砖，而是换一条正常的烧录路径。
`PA15 AF1 = USART1_RX`，需要 RX 时可一并使用（发布版不跑 `motor_cycles.c` 的示波器测试点）。

### 9.6.2 前提：BOOT0 必须可设置（已添加）

原设计 BOOT0 只有 `R17` 10k 下拉、未引出任何位置，无法进 bootloader。已追加：

| 器件 | 连接 | 说明 |
|---|---|---|
| `JP3` Jumper_2_Open | `+3V3` ↔ `BOOT0` | 闭合 = 复位时 BOOT0 高 = 进 bootloader；断开时 `R17` 保持低（闭合时跳线胜出，耗流 330 µA） |
（BOOT0 的探测点就用 `JP3` pin 2，不另设测试点。）

两条恢复路径由此都成立：

| 路径 | 前提 | 现状 |
|---|---|---|
| SWD connect-under-reset | NRST 可控 + 固件不过早切 AF | `NRST → J9.5` 已引出，`openocd.cfg` 为 `srst_only` ✓ |
| 系统 bootloader（PA14/PA15 串口） | BOOT0 可拉高 | **`JP3` 已添加** ✓ |

### 9.6.3 调试口串阻（`R35`/`R36`，各 100 Ω）

PA14 复用 SWCLK / USART1_TX；PA13 复用 SWDIO / **红外输出**（`IR_OUT`）。
发布固件可能在两脚上推挽驱动，而调试器或红外接收头仍连着排针 → 须限流。

```
U1.24 (PA14) ── R35 100R ── SWCLK ── J9.3 / J12.2     （网表标签亦作 USART1_TX 注释）
U1.23 (PA13) ── R36 100R ── IR_OUT ── J9.2 / J11.2
U1.25 (PA15) ── TP1 (TP_CYCLE)                        （bootloader 时作 USART1_RX）
```

对顶电流约 **3.3 V / 100 Ω ≈ 33 mA**。`J9` **不引出 SWDIO**——全功能 SWD 需飞线到
MCU 侧测试点，或依赖 connect-under-reset + bootloader（§9.6.2）。

### 9.6.4 固件侧约束

1. **切 AF 的时机不能早。** connect-under-reset 需要探头有一个窗口。
   建议做成**编译期选择**：调试版保留 SWCLK，发布版才切 USART1_TX。

### 10.2 为什么用「线头 + 网络标签」风格

每个引脚接一段短线加一个网络标签，而不是画点对点连线。图不好看，但

- 连接关系由**标签**承载，与摆放位置无关——在 Eeschema 里重新排版**不会破坏网表**；
- 网表就是生成脚本里那张表所写的内容，可被 `check_netlist.py` 机器核验，
  不依赖人眼看图。

因此可以在 KiCad 里拖动器件、重排版面。**改连接**须改 `gen_schematic.py` 并重新生成；
重新生成会覆盖 `.kicad_sch` 上的手工连线，排版后若需保留布局请先备份或只在 Eeschema 里动位置。

### 10.3 `check_netlist.py` 核验的内容

**验证拓扑与功能，不验证网络名。** 手工连线处 KiCad 会自动命名（如 `Net-(J5-Pin_1)`），
所以分流链路检查的是「`J5.2` 是否经**恰好一个器件**到达 `U2` 的 `IN+`」，
而不是「那条网络是否叫 `SHU_P`」。这样在 Eeschema 里改标签、删标签都不会让校验失效，
只有真正改错接线才会。

| 检查项 | 依据 | 为何重要 |
|---|---|---|
| 3 × INA240 全部 8 脚（含拓扑） | TI SBOS712 Table 6-1 (D/SOIC) | **KiCad 自带符号 D/PW 引脚对调，接错即上电烧件**（§1.3） |
| MCU 全部 32 脚 | 本文 §3 / `board_pins.h` | 固件与硬件的唯一接口 |
| `J2..J4` / `J5..J7` | 半桥板 `J3` / `J2` 实际网表 | 接错会把 PWM 灌进分流节点 |
| **6 路过流 + 2 路过温，无置死单元** | 本文 §2 / §6.2 | 按**功能集合**判定，不锁定哪个物理单元做哪件事（编排是布局自由度） |
| `D5` 单向 OR 方向 + `nOTEMP` 唯一上拉 | 本文 §6.2 | 方向画反则过流会伪装成过温；重复上拉是画图漏删 |
| 输入保护链 `J1→F1→D6→+12V`、`D7` 在中间节点 | 本文 §4.1 | `D6` 方向画反则整板串一个反偏二极管；`D7` 位置决定 `F1` 能否保护它 |

| INA240 `REF1`/`REF2` 按**集合**判定 | 本文 §1.2.1 | 数据表称两脚无功能差异，分配是布局自由度 |
| `R37` + `J12` 三脚 UART | 本文 §9.6 | PA15 复用对顶保护 + bootloader 引脚对可达 |

| PA4 / PA5 分压 | 本文 §9.5.1 / §9.5.2 | `vdc` 是 FOC 必需输入 |
| 3-BJT 电荷泵 + `V_BOOST` 直出 | 本文 §9.5.3 | 成本方案；无 TC4427 / 无 JP1 |

### 10.4 关于双重标签

原理图上多处同一网络挂了两个标签（如 `PWM_V_L` 与 `TIM1_CH2N`、`ADC_IN1` 与 `ISENSE_U`），
作为「信号名 + 外设功能」的双重注释。ERC 会报 `multiple_net_names` 警告，无害，
但要注意 **KiCad 取第一个名字进网表**。校验脚本按进入网表的那个名字判定。
