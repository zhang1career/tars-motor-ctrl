# 电机控制调试：给你看的入口

仓库里的 [`roadmap.md`](../roadmap.md) 是给接手干活的人用的操作手册。这里四份短文只回答一件事：**这台电机上，控制程序是怎么调出来的，调到哪一步就停了。**

| [2. 节点指标和测法](02-metrics.md) | 每一步看哪个数、怎么测、过了算过 |
| [3. 翻过的坑](03-troubles.md) | 哪些「电机坏了」其实是测量或硬件在骗人 |
| [4. Simulink 和定点](04-simulink-and-fixed-point.md) | `sim/` 用了没有、和仿真差多远、为什么不用浮点 |

日常转电机走 **TARS I²C**，不走 SWD 调参。Mac：`TARS_CDC=… ./src/firmware/stm32f030/scripts/mot_i2c.sh start`（默认 1200 mA / 40 电周期/秒）。地址 `0x50`，产品号 `0x0005`。UART 只出人看的日志（PA14 → nanoDAP）。成绩仍看 wrap。

数字以 [`report/speed-loop-20260914.md`](../report/speed-loop-20260914.md) 和路线图顶部「当前进度」为准。采数在 `models/captured/`，不进 Git。

## 十个词

| 词 | 人话 |
|---|---|
| 六步 / hall6 | 霍尔传感器告诉转子在六个扇区里的哪一个，程序轮流给两相通电。能转，但力矩一顿一顿。 |
| FOC | 矢量控制。每秒两万次把三相电流拧成两个数来调。 |
| id | 顺着磁铁的电流。理想为 0。不对零，多半是角度没对准。 |
| iq | 产生力矩的电流。制动器拧紧，iq 要加大。 |
| 电角度 / wrap | 转子转过的电角度。这台电机 4 极对，轴转一圈电角度转四圈。成绩用 wrap（净角度 ÷ 墙钟时间），不用芯片自己报的转速表头。 |
| 母线 | 电源给半桥的直流电压，名义 12 V。 |
| 占空比 / PWM | 每个开关周期里高边导通的比例。电压就是靠这个「切」出来的。 |
| 电压顶 | PWM 已经打满，再快就要加电压或减载。 |
| 弱磁 | 故意加负 id，把磁链削薄，好在同一电压下转更快。这台电机做不到有用的弱磁。 |
| 定点 | 不用小数，用整数表示电流、电压。这颗芯片没有浮点硬件。 |
