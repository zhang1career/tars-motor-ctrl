# 2. 各节点：看什么、怎么测、怎样算过

每一行的「过」都要有**两个独立证据**。对上参考实现的电流、但轴没转，这种事发生过。

通电固定动作：探头在线 → 烧录校验 → CPU 在跑（毫秒计数在走）→ 从芯片读回参数（不要信自己刚传进去的数）→ 测完刷回「上电不自启动」固件，空载回到约 4 mA。

一条命令过自检：`./src/firmware/stm32f030/scripts/board_check.sh`

速度环开跑（刻度先问人，不要自己假设）：

```bash
FAST=1 DIRS=0 IQ_LSB=434 SPD_S=8 W_REFS="80 130" VQMAX_UV=6580000 \
  SKIP_TRACE=1 ./src/firmware/stm32f030/scripts/foc_current.sh
```

先开速度环，再抬电压上限。母线超过 0.50 A 一律停。

---

## 六步（回归基准）

| 看什么 | 怎么测 | 过线 |
|---|---|---|
| 轴在转 | 霍尔边沿计数随时间增加 | 不是「电流有了」就算转 |
| 母线电流形状 | 随有效导通时间应大致平方，不是直线 | 直线先查半桥输出电容有没有被装回 |
| 工作点 | duty 20%，约 60–70 mA，约 24 电周期/秒 | 和旧基线同量级 |
| 电源没限流 | C.C. 灯 + 母线电压没塌 | 限流时所有软件对比作废 |

## A 观测

| 看什么 | 怎么测 | 过线 |
|---|---|---|
| 波形是连续的一截 | 环形缓冲填满再读；读之前冻结 | 边沿样本的「距上一沿拍数」必须小于抽取比，否则时间轴是假的 |
| 一拍要多少时间 | `ctrl_bench`，电机不通电 | 20 kHz = 每拍 2400 周期。后面算法必须把自己装进这个预算 |
| Hall 扇区宽 | 同一缓冲里数六个码的时长 | 记录下来。六个扇区**本来就不等宽**，不要当成传感器坏了 |

## B 算得动吗

| 看什么 | 怎么测 | 过线 |
|---|---|---|
| 生成的浮点 FOC | 链进固件只调用、不驱动电机，数周期 | 1.5～1.8 万周期。20 kHz 装不下 |
| 手写浮点简化版 | 同上 | 16173 周期。同样装不下 |
| 定点 `MotorFocFx_Step` | 同上 | 中位数必须小于 1837 周期 |
| 定点没有偷偷用浮点 | 反汇编里搜 `__aeabi_f*` | 只允许整数除法。出现任何浮点符号就不算过 |
| 定点和浮点算的是同一件事 | 同一组假 ADC / 假角度，比 id、iq | 每组差不超过 4 mA |

电流环带宽公式用实测电阻、电感：每相 0.65 Ω、437 µH，电气极点约 236 Hz。20 kHz 采样远大于 10 倍极点，带宽选 1200 Hz。

## C 电流眼

| 看什么 | 怎么测 | 过线 |
|---|---|---|
| 一格代表多少毫安 | 静态单步通电，ADC 对万用表反推的绕组电流 | 1.617 mA/格；有效导通 > 8% 时比值 0.99±0.02 |
| 零点 | 不通电读三路 | 钉在 2048，三路 ±3 格，不用软件校零 |
| 三相和 | `iu+iv+iw` | 残差大约满量程的 0.2%（星形接法应为 0，剩下的是测量误差） |
| 采样点 | 示波器对时标，不拿示波器当电流表 | 必须落在**低边导通**窗口里，离开关沿远 |

大约 150 电周期/秒以上，最高那一相占空比打满，低边窗口没了。这时 `|i0|>10 mA`，**电流均值一律作废，只信 wrap**。不要再扫采样提前量。

## D 连续角度

| 看什么 | 怎么测 | 过线 |
|---|---|---|
| 边沿处跳变 | 缓冲里同时记霍尔码和电角度 | 最大约 1.2°（指标 < 10°） |
| 转速和外推 | 角度斜率对霍尔边沿计数 | 差 0.5%（指标 < 3%） |
| 六个锚点均匀 | 用时间间隔推几何 | **不过。** 53–68°。时间间隔里混着六步力矩脉动，不能当几何真理 |
| 绝对零点 | 留给 E：看 id 是否接近 0 | 用 id 当仪器，不用带载时间间隔 |

## E 电流环

| 看什么 | 怎么测 | 过线 |
|---|---|---|
| 先只看不驱动 | 电机仍由六步转，FOC 只算 id/iq | id 接近 0，iq 和力矩同向 |
| 再闭合 | 六步交接后由 FOC 出电压 | id 压在 0 附近，iq 跟电流指令 |
| 保护 | 比较器 → 芯片刹车脚；软件母线 0.50 A | 加大电流之前必须开着 |
| 过流硬件 | hall6 20% 和大约 ±1.3 A 两相 | 刹车标志不误跳 |

## F 速度环

| 看什么 | 怎么测 | 过线 |
|---|---|---|
| 稳态 | 指令 80、130，正反转，成绩用 wrap | 抱住。不要给转速再加半拍（加了会高 0.9–1.4%） |
| 阶跃 | 80→130，100 ms 滑窗看 10–90% | 刻度 3 大约 290–320 ms，超调大约 +1 |
| 力矩 | 刻度 0–5，同一转速看 iq | 膝盖在 3→4。Kt = 0.0378 N·m/A。同一格位 iq 约 ±3 mA；**拨一次盘大约 20 mA** |
| 磁链 | 未饱和时 `(vq − R·iq) / 电角速度` | λ = 6.3 mWb。和母线功率核对，差约 2% |
| 电压顶 | 线性圆电压 = 母线 / √3 | 12 V、刻度 4：wrap **174 @ 175** |
| 扰动 | 抱住 80，刻度 3→4 整格。`mot_i2c.sh disturb` 记，Glass 时拧 | 2026-09-16：拧前 wrap≈66、iq≈330 mA。拧后 Δiq +90…130 mA，wrap 最低 61–63，约 2.5 s 拉回拧前±2，无故障。门限跟拧前 wrap，不跟 80。I²C 连读时 `w` 会偏高，成绩只看 wrap |

## G 弱磁（关闭）与过调制

| 看什么 | 怎么测 | 过线 |
|---|---|---|
| 该不该弱磁 | 特征电流 λ/Ld 对台架电流帽 | 14.4 A 对大约 3 A → 没有恒功率区，关闭 |
| 试过的负 id | 刻度 4、160，id = 0 / −100 / −200 mA | wrap 不升 |
| 温升 | 刻度 4（上次扰动停在这）、w=80，`mot_i2c.sh thermal` 20 min | 2026-09-16：800 点。wrap 均值 66.2 抱住，iq 396…451 mA，无故障。片内 TEMP 29.5 °C 全程未动 |
| 再挤 12 V | 加大电流指令、关死区补偿、拧 Park 角度 | 指令 800–1000 停在 wrap **188**。关死区更慢。Park 不是瓶颈 |
| 加电压 | 15 V，线性圆 8.41 V | wrap **213 @ 220**。过调制不再快 |

12 V 刻度 4 的软件转速猎取到此为止。
