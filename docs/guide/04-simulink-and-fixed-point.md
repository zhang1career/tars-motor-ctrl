# 4. Simulink 用了没有，定点和浮点差在哪

## 短答

| 问题 | 答案 |
|---|---|
| 台上跑的是 Simulink 生成的程序吗？ | **不是。** 芯片跑手写定点 `src/platforms/stm32f030/motor_foc_fx.c` |
| `sim/` 完全没用来过吗？ | **用过配方，没用过仿真当裁判。** 电流环「怎么算增益」和 Clarke / Park / 两路 PI / SVPWM 的步骤来自 `sim/`。生成的 C 只拿来测了一次周期数，然后放弃 |
| 现在的成绩能和 `run_sim` 那张图对上吗？ | **不能直接对。** 那是另一台电机、另一种控制、另一种芯片上的理想仿真 |
| 定点会不会比浮点「算不准」所以转不快？ | **不会。** 转不快是电压和这台电机的磁链、电感。定点相对浮点对照，id/iq 差不超过 4 mA |

## `sim/` 里到底是什么

`sim/` 是一份 **MATLAB/Simulink 教学模型**，写给 STM32F429（有硬件浮点）用的：

- 电机当初按「24 V、60 W、3000 rpm」的**估算**来写，不是这只台架电机
- 控制是**无感** FOC：用反电势估角度，加开环起转，再交给观测器
- 逆变器是平均模型，电流永远采得到，没有霍尔、没有磁粉制动器、没有低边窗口消失
- `gen_code.m` 生成单精度 C，放在 `sim/codegen_stm32/`（不进 Git，也不刷这颗 F030）

台上实际多了：霍尔、六步交接、死区、电荷泵、0.50 A 停机、制动器非线性、高占空比时电流眼瞎掉。这些仿真里都没有。

## 调试时 `sim/` 扮演的角色

**用过的**

- 算法步骤：电流 → Clarke → Park → 两个 PI → 逆 Park → SVPWM。定点任务书逐步对应 `foc_controller_step.m` 的若干步。
- 电流环增益公式：带宽 × 电感、带宽 × 电阻。芯片上的数用**台架测过的** 0.65 Ω、437 µH 算出来，再折进 1.617 mA/格。和 `mc_params.m` 里后来写上的 `[MEASURED]` 是同一套公式。
- 磁链、极对数、母线 12 V、电流帽 3 A：测完写回 `mc_params.m`，当作参数真源，**不是**再生成一份固件。
- 阶段 B：把生成的 `foc_step_stm32()` 链进板子**只计时、不驱动**。结论是 1.5～1.8 万周期，20 kHz 装不下。

**明确没用的**

- 没有把台架闭环曲线和 `run_sim` 叠在一张图上比。
- 没有用仿真里的无感观测器、PLL、开环起转。台上是霍尔 + 六步交接。
- 没有用仿真里的速度环增益。那组增益带着未测的转动惯量 `J`。路线图写明：不要把 MATLAB 的 `Kp_w` / `Ki_w` 当成芯片上的环。
- 没有改、也没有再生成 `codegen_stm32/`。

所以：**配方和电流环时间常数用了 `sim/`；闭环成绩是台架抠出来的。** 不是「完全没利用」，也不是「仿真调好再下载」。

## 和仿真能差多大

把两边摆在一起，差的不是小数点，是题目：

| | Simulink `run_sim` | 这套台架 |
|---|---|---|
| 电机 | 估算的 24 V 机，λ 曾按 8.5 mWb | 实测 λ 6.3 mWb，L 437 µH |
| 母线 | 24 V | 12 V（试过 15 V） |
| 位置 | 无感，稳态角度误差大约几度 | 霍尔 + 外推；扇区不等宽 |
| 负载 | 仿真里加 0.1 N·m | 磁粉制动器，刻度非线性 |
| 电流反馈 | 理想 | 约 150 以上窗口没了 |
| 速度环 | 按估算惯量、25 Hz 带宽设计 | 台上调到能抱 80/130，阶跃约 300 ms |
| 弱磁 | 模型里有电流余量 | λ/Ld = 14.4 A，做不了 |
| 芯片 | F429 硬件浮点，生成代码约 1.5 KB | F030 定点手写，整包大约 11 KB |

仿真那张图：无感交接到闭环，稳住 1500 rpm，突加负载 iq 大约到 2 A。台上：12 V 刻度 4 电压顶在 wrap 174～188（电周期/秒），15 V 到 213。两边转速单位都不要硬换——电机、电压、负载都不是同一个。

若以后要用 Simulink 当裁判，最少要把植物换成这只电机的 R/L/λ、12 V、霍尔角度、带死区和采样窗口的逆变器，并且**不要**再用那组未测 `J` 的速度 PI 去对台上的 300 ms。那样比的是模型，不是今天这份生成代码。

现在去做这件事，帮不了 12 V 再快一点。它只帮「下一台合适的电机」先在电脑上看到弱磁区。

## 定点是什么，和浮点差在哪

**浮点**：数可以带小数，写法接近公式。这颗 Cortex-M0 **没有浮点硬件**，每一记加减乘除都要跳进软件库。测过：一次乘法 169 周期；一次完整浮点 FOC 16173 周期。控制必须每 50 微秒来一拍（20 kHz），整拍只有 2400 周期，还要留采样和输出。浮点一整步就要 337 微秒，环最多大约 3 kHz，电流环刚够、没有余量。

早先按「每次浮点大约 35 周期」估过「简化版 2000 周期就能跑 10 kHz」。假设错了大约 5 倍。所以定点不是口味，是被秒表逼的。

**定点**：几乎不用小数。电流用 ADC 格子，电压用微伏，正弦用一张 256 项整数表。积分器比信号路径更宽，避免「误差太小、加上去还是零」。饱和必须自己写死——这颗芯片溢出不会饱和，会翻转符号。

和浮点实现逐点对照（同一组假输入）：id、iq 相差不超过 4 mA，大约 2～3 个 ADC 格。这是截断，不是另一套控制。

| | 浮点（`motor_foc.c` / 生成代码） | 定点（台上在跑的） |
|---|---|---|
| 一拍时间 | 大约 1.6 万周期 | 必须 < 1837 周期才进 20 kHz |
| 精度对控制 | 公式好看 | 对照差 ≤ 4 mA，不是转速瓶颈 |
| 调试 | 变量就是伏特、安培 | 名字里带着单位；环形缓冲里都是整数 |
| 换增益 | MATLAB 改完再生成 | 改两个整数常数，不必走代码生成 |

台上转不快，换成浮点（或换一颗带浮点的大芯片跑同一套 Simulink 代码）**也不会**在 12 V 刻度 4 上突破电压顶。浮点解决的是「算得完」，不是「电压不够」或「这台电机弱磁没用」。
