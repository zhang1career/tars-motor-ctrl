# 3. 遇到过什么，怎么排除

共性：**装置坏了，结论却写在电机头上。** 负面结果先证明测量链是活的，再改算法。完整清单在 [`measurement-validity.md`](../measurement-validity.md)。

## 先排除「你在测假东西」

| 表象 | 容易误判成 | 实际 | 怎么排除 |
|---|---|---|---|
| 母线 0.000 A，引脚全平 | 板子烧了 | 调试探头掉了（芯片靠探头供电） | 先查探头。空载有 12 V 时应约 4 mA |
| 外设不动、电流像空载 | 固件没输出 | 烧录后 CPU 停在复位断点，没跑到主程序 | 烧录脚本必须清断点再继续 |
| 波形全平 | 硬件坏 | 烧录失败，芯片还在跑旧程序 | 不要把烧录输出扔进垃圾桶；必须看到校验通过 |
| 故障线是高电平 | 保护正常 | 12 V 没上，比较器没电，开集输出假装「无故障」 | 先确认母线 > 10.5 V |
| 行为与参数不符 | 代码逻辑错 | 编译缓存仍是上次的选项；或函数内部把参数悄悄夹掉 | 从芯片读回。换参数组先清构建目录 |
| 快照是垃圾 | 固件没更新状态 | RAM 地址写死在脚本里，链接后地址漂了 | 用符号名从 ELF 解析 |
| 六步电流完全一样 | 三相对称、功率级好 | 「固定单步」被限幅成每 500 ms 换一次相 | 先读回步长时间 |
| 36 种线序/相位电流都一样 | 霍尔全错 | 电源已经限流，母线塌了 | 看 C.C. 灯和母线电压，不看面板 10 mA 分辨率的电流表 |
| 电流随导通时间**直线**上升，大约 1.5 A | 桥臂短路 | 半桥输出滤波电容还在，电容在充放电 | 电容必须拆掉。真绕组电流大致随 duty **平方** |
| 漂亮的电流波形，转速差一倍 | Hall 少码 / 传感器坏 | 边读边写 12.8 ms 的缓冲，读了 1 秒，时间轴是拼出来的 | 读之前冻结缓冲 |
| 控制环「跑在 25.7 kHz」 | 定时器配错 | 两次读数中间夹了别的操作，除数用了墙上的 6 秒，实际隔了 7.7 秒 | 同一次调试会话里只等待；环频用定时器寄存器算 |
| 示波器说放大器要 24 µs 才稳 | 芯片太慢 | 示波器垂直档太粗，量化误差当成噪声 | 示波器在这里用来对时，不用来当电流表 |
| 浮点 FOC「大约 2000 周期，10 kHz 够」 | 方案可行 | 软浮点一次乘法 169 周期，不是口算的 35。整步 16173 周期 | 先测一次乘法，再估整步。反汇编数调用次数 |

## 功率级和六步

| 坑 | 怎么打 |
|---|---|
| 低边常通写成「比较值 = 0」 | 这颗芯片这样配会让低边恒关，电机零力矩。低边常通必须把比较值设到周期以上 |
| 中心对齐忘了「重复计数 = 1」 | 控制环会跑成 40 kHz，所有时间常数差一倍 |
| 照抄另一块板的 duty 百分比 | 死区要从高边脉冲里减掉。对齐的是有效导通时间，不是屏幕上的百分数 |
| 反转只移相、不换驱动表 | 六个相位里只有两个高效；抄反了会没力 |
| 电机根本没接上 | 万用表：三相相间都应是 1.3 Ω；短接两相手转轴应变沉 |

## 电流和角度

| 坑 | 怎么打 |
|---|---|
| 用带载扇区时间标定霍尔安装角 | 六步力矩脉动和几何偏差锁在同一组码上，分不开。改用 id 是否为零 |
| 诊断脉冲打在电流采样线上 | 百毫伏尖峰会污染 ±30 mV 的真信号。时标默认关 |
| 大约 150 以上电流变垃圾 | 最高相已经打满，低边采不到电流。不要扫提前量，不要用这时的 iq 当成绩 |
| 给转速加半拍 | 偏差从「略低」翻成「高 0.9–1.4%」。`dwell+1` 之后不要再加 |

## 电流环、速度环、过调制

| 坑 | 怎么打 |
|---|---|
| 角度没标定就闭合电流环 | 电流会打进 d 轴。先六步转着，只观测 id/iq |
| 过调制时积分器不回灌 | 芯片以为电压还能再加，实际已经被六边形夹住 → 电压来回猎。饱和时用**实际打出去的电压**重写积分器 |
| 同一 6.58 V 上开过调制 | 比线性圆更慢。电流已经是垃圾，去掉圆钳位后矢量被带偏。不要再比这一组 |
| 过调制的同时改角度限速、还拧制动盘 | 转速掉到 151，账算不清。一次只动一件事，速度顶实验不要拧盘 |
| 再抬转速指令或 Park 限速冲 200 | 12 V、电流指令 434 时仍是 179。电压顶，不是角度顶 |
| 把 MATLAB 速度环增益抄上芯片 | 那组增益用了未测的转动惯量。芯片上的环是台架调出来的 |
| 为了实验通过而拧高电源限流 | 撞限流说明工作点或寄生通路错了。先找原因 |

## 三条总是先问的

1. **空载是不是约 4 mA？** 不是，先查探头、12 V、是否还挂着会转的固件。
2. **电流随 duty 是平方还是直线？** 直线先查输出电容。
3. **这个数有第二个判据吗？** 电流对上了，轴转了没有？电压顶了，PWM 比较值是不是已经等于周期？
